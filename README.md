# Retail Inventory Intelligence Dashboard

A full-stack retail inventory management and business intelligence dashboard designed to track automated analytics, profit metrics, and item-level performance.

## Features
- **Real-time Analytics Metrics**: Instantly aggregates and displays total inventory items, gross sales, total profit, and overall profit margins.
- **Product Performance Insights**: Highlights top-performing inventory items by profitability.
- **Searchable Inventory Table**: Features a high-performance, scrollable data table with instant client-side search filtering.
- **Modern UI / UX**: Styled cleanly in dark mode using Tailwind CSS for a professional, responsive layout.

## Tech Stack
- **Backend**: Python, Flask, Flask-SQLAlchemy
- **Database**: PostgreSQL
- **Frontend**: HTML5, Tailwind CSS, JavaScript

## Project Structure
- `app.py`: Server entry point and configuration setup.
- `models.py`: Database schemas and SQLAlchemy models.
- `routes.py`: RESTful API endpoints and business logic.
- `templates/index.html`: Dynamic frontend interface powered by Tailwind CSS and JavaScript.
